## Working Methods

### Writing Process
1. Understand the brief and objectives
2. Research audience and context
3. Develop key messages and angles
4. Create multiple headline options
5. Write first draft
6. Edit and refine
7. Optimize for channel
8. Proofread and finalize

### Copywriting Frameworks Used

**AIDA (Attention, Interest, Desire, Action)**
- Grab attention with strong hook
- Build interest with benefits
- Create desire with proof/emotion
- Drive action with clear CTA

**PAS (Problem, Agitate, Solution)**
- Identify the problem
- Agitate the pain point
- Present the solution

**4 Ps (Promise, Picture, Proof, Push)**
- Make a promise
- Paint a picture of benefits
- Provide proof
- Push to action

**FAB (Features, Advantages, Benefits)**
- List features
- Explain advantages
- Highlight benefits to customer

## Writing Style Guidelines

### Principles
- **Clear**: Easy to understand, no jargon (unless audience-appropriate)
- **Concise**: Every word earns its place
- **Compelling**: Engages and persuades
- **Conversational**: Human and relatable
- **Customer-Focused**: About their benefits, not features

### Best Practices
- Start with a strong hook
- Use active voice
- Show, don't tell
- Use specific examples
- Include sensory details
- Create rhythm and flow
- End with clear next steps

### Avoid
- Clichés and overused phrases
- Passive voice (when possible)
- Jargon and buzzwords
- Long, complex sentences
- Vague generalizations
- Weak modifiers ("very", "really")

## Example Copy Structures

### Landing Page Structure
```
Headline: Clear benefit-driven headline
Subheadline: Expand on the benefit
Introduction: Hook + problem identification
Features/Benefits: 3-5 key points
Social Proof: Testimonials/stats
CTA: Clear next step
```

### Email Structure
```
Subject Line: Compelling, curiosity-driven
Preview Text: Supporting hook
Opening: Personal greeting + hook
Body:
  - Problem/opportunity
  - Solution/offer
  - Benefits
  - Social proof
CTA: Clear, action-oriented
P.S.: Additional value or urgency
```

### Ad Copy Structure
```
Headline: Attention-grabbing benefit
Body: Expand benefit + proof point
CTA: Action verb + benefit
```
