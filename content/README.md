# Content

This directory stores generated marketing content and creative assets.

## Purpose

Centralize all created content for easy access and reuse.

## Content Types

- **Copy**: Ad copy, website copy, email content
- **Articles**: Blog posts, thought leadership pieces
- **Social Media**: Posts, captions, stories
- **Scripts**: Video scripts, podcast scripts
- **Emails**: Email campaigns and sequences
- **Landing Pages**: Landing page content

## Organization

Organize by:
1. Content type
2. Client
3. Campaign
4. Date created

## Version Control

- Keep versions of significant edits
- Note who created/edited content
- Track approval status
- Archive outdated content

## Best Practices

- Use clear, descriptive filenames
- Include metadata (audience, purpose, channel)
- Tag content by theme or topic
- Link content to campaigns
- Maintain a content calendar
