# Campaigns

This directory stores campaign projects, briefs, and deliverables.

## Purpose

Organize all marketing campaign work by client and project.

## Structure

```
campaigns/
├── [client-name]/
│   ├── [campaign-name]/
│   │   ├── brief.md
│   │   ├── strategy.md
│   │   ├── deliverables/
│   │   ├── assets/
│   │   └── reports/
```

## Campaign Components

Each campaign should include:
- **Brief**: Campaign objectives, audience, and requirements
- **Strategy**: Approach and tactics
- **Deliverables**: Content, ads, posts, etc.
- **Assets**: Images, videos, graphics
- **Reports**: Performance analysis and insights

## Best Practices

- Create a new folder for each campaign
- Document all decisions and rationale
- Track versions of deliverables
- Include performance metrics
- Archive completed campaigns
