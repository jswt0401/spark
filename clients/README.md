# Clients

This directory contains client profiles, brand guidelines, and requirements.

## Purpose

Store comprehensive information about each client to ensure consistent, on-brand work.

## Structure

```
clients/
├── [client-name]/
│   ├── profile.md
│   ├── brand-guidelines.md
│   ├── target-audience.md
│   ├── competitors.md
│   └── assets/
```

## Client Profile Contents

Each client folder should include:
- **Profile**: Company overview, industry, and business model
- **Brand Guidelines**: Voice, tone, visual identity
- **Target Audience**: Demographics, psychographics, behaviors
- **Competitors**: Competitive landscape analysis
- **Assets**: Logos, brand materials, references

## Best Practices

- Keep client information up to date
- Document all brand requirements
- Note preferred communication styles
- Track client feedback and preferences
- Maintain confidentiality
