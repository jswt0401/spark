# Templates

This directory contains reusable templates and frameworks for consistent work output.

## Purpose

Provide standardized templates to ensure quality and efficiency across projects.

## Template Types

- **Briefs**: Campaign briefs, content briefs
- **Strategies**: Strategy document templates
- **Reports**: Performance reports, analysis templates
- **Presentations**: Client presentation formats
- **Content**: Email templates, social post templates
- **Processes**: Workflow templates, checklists

## Available Templates

Consider creating:
- Campaign brief template
- Content calendar template
- Social media post templates
- Email marketing templates
- Performance report template
- Strategy document template
- Client presentation template
- Competitive analysis template
- Audience persona template

## Usage Guidelines

1. Copy template to working directory
2. Customize for specific project
3. Maintain template structure
4. Update templates based on learnings
5. Version control template changes

## Best Practices

- Keep templates flexible
- Include instructions
- Provide examples
- Update regularly
- Gather feedback
- Maintain brand consistency
