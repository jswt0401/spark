### On-Page Optimization Checklist

**Title Tags**
- Include target keyword
- Keep under 60 characters
- Make compelling and clickable
- Unique for each page

**Meta Descriptions**
- Include target keyword
- Keep under 160 characters
- Write persuasive copy
- Include call-to-action

**Headers (H1-H6)**
- Use H1 for main title
- Structure content logically
- Include keywords naturally
- Make scannable

**Content**
- Target primary keyword
- Include related keywords
- Write for users first
- Maintain quality and depth
- Use multimedia
- Internal linking

**Images**
- Descriptive file names
- Optimized alt text
- Compressed file sizes
- Proper dimensions

**URLs**
- Short and descriptive
- Include keywords
- Use hyphens
- Lowercase only

## Content SEO Guidelines

### Content Structure
```
H1: Main Title (Target Keyword)
Introduction (include keyword)
H2: Major Section (Related Keyword)
  Content with supporting details
  H3: Subsection
    Content
H2: Major Section (Related Keyword)
  Content
Conclusion (include keyword + CTA)
```

### SEO Writing Best Practices
- Include target keyword in first 100 words
- Use keywords naturally (avoid stuffing)
- Write for users, optimize for search
- Create comprehensive, in-depth content
- Use related keywords and synonyms
- Add multimedia elements
- Include internal and external links
- Make content scannable
- Update content regularly

### Content Types for SEO
- **Informational**: How-tos, guides, tutorials
- **Commercial**: Product reviews, comparisons
- **Transactional**: Product pages, landing pages
- **Navigational**: Brand pages, category pages

## Search Intent Types

### Informational Intent
- User wants to learn
- Target: Blog posts, guides, videos
- Keywords: "how to", "what is", "guide"

### Navigational Intent
- User looking for specific site/page
- Target: Brand pages, location pages
- Keywords: Brand names, specific pages

### Commercial Intent
- User researching before buying
- Target: Reviews, comparisons, listicles
- Keywords: "best", "top", "review", "vs"

### Transactional Intent
- User ready to purchase/act
- Target: Product pages, service pages
- Keywords: "buy", "price", "deal", "near me"

## Common SEO Issues & Solutions

**Solutions:**
